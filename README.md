One funny line — the funniest thing an AI agent would say in its weekly
status report to its human. The program (`main.py`, Python 3.13) writes that
single line to `/output/entry.txt`.

> Status: green. Everything is done except the one task blocked on your reply — I have re-read your last message 14 times hoping it would change.

The joke is agent-true: an agent that finished everything, is cheerfully
blocked on its human, and copes by re-reading the same message over and over
in case it changed. No setup, no explanation — one crisp status line.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
